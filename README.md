# Biome World — Telegram Mini App

## Постоянный хост через GitHub

Игра в ветке **`gh-pages`**: `index.html` + `bg-music.mp3`.

### Включи GitHub Pages (один раз, 30 секунд)

1. Открой: https://github.com/t17067042-code/biome-world-tg/settings/pages
2. **Source** → Deploy from a branch
3. **Branch** → `gh-pages` / `/ (root)` → **Save**

Сайт: **https://t17067042-code.github.io/biome-world-tg/**

### Уже работает без включения Pages (CDN GitHub)

https://cdn.jsdelivr.net/gh/t17067042-code/biome-world-tg@gh-pages/index.html

### Деплой

Actions → **Deploy Biome World** → Run workflow  
или push в `main` (обновляет `gh-pages`).
